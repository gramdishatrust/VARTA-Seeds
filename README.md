# VARTA-Seeds (वार्ता-बीज)

An open-source Digital Public Good (DPG) and neurosymbolic decision engine for crop variety, cultivar, and rootstock matching.

## Architecture
- **Bīja-Sabhāva (बीज-सभाव):** Phenological & climate matching engine for annual field crops and traditional landraces (paddy, millets).
- **Aslofuru (अस्लोफ़ुरू / اصل و فروع):** Two-pass matching engine for grafted perennial fruit trees (apple, citrus, grapes, guava, mango, stone fruit).
- **Standards Compliance:** BrAPI v2.1 (`/germplasm`, `/variables`), FAO/Bioversity MCPD v2.1, and UPOV Test Guidelines.
